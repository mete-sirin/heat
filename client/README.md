# HEAT - Frontend

I vibecoded this frontend using _React 19_, _Tailwind CSS_, and _TanStack Query_ just to have a clean, working dashboard to test my backend endpoints and use the app.

It doesn't offer anything crazy. The main focus of this whole project is the backend, database design, and the Linux VPS setup.

If you're here to check out the actual engineering work, check these out instead:

- [**Backend & VPS Setup Deep-Dive**](../server/README.md)
